Access-Control-Allow-Headers: * does not cover Authorization.
Open the app
A request with an Authorization header and a server that answers Access-Control-Allow-Headers: * is still blocked. So is Access-Control-Allow-Origin: * when the request sends cookies.

What it does

  • Says whether a preflight is needed, and exactly why
  • Walks the preflight and the real response check by check
  • Handles credentials, wildcards, Authorization and method case
  • Shows the header line that fixes the first failure
